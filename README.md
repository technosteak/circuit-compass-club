# Circuit Compass Club

Создай профессиональный, светлый, воздушный и современный интернет-каталог-обзорник техники под названием "ТехноСтейк" (technosteak.ru). Дизайн должен быть чистым, премиальным и удобным, на уровне лучших маркетплейсов (в стиле Ozon/Яндекс Маркет), но с акцентом на обзоры и выбор товаров.

Технические требования к архитектуре:
- Проект должен быть полностью статическим (HTML / Tailwind CSS / чистый JS или легкий роутинг), чтобы его можно было без проблем развернуть на GitHub Pages.
- Все данные товаров (название, цена, категория, рейтинг, характеристики, ссылки на фото, ID видео с YouTube и партнерские ссылки на Яндекс Маркет) должны выноситься в отдельный структурированный JSON-файл (например, `products.json`). Интерфейс должен динамически строить карточки и страницы на основе этого файла, чтобы внешний сервер мог легко обновлять его скриптами.

Цветовая палитра:
- Основной фон: чистый белый (#FFFFFF) и очень мягкий светло-серый (#F8FAFC) для блоков.
- Акценты: глубокий технологичный синий/индиго (#2563EB) для кнопок и ссылок, темно-серый (#1E293B) для текста.
- Карточки товаров: белые, с тончайшими тенями и эффектом легкого подъема при наведении.

Структура главной страницы:
1. Шапка (Header): 
   - Логотип "ТехноСтейк" с фирменной иконкой.
   - Интерактивное меню категорий (Смартфоны, Ноутбуки, Игры, Умный дом, Аудио).
   - Полноценная рабочая строка поиска по каталогу.
   - Иконка избранного (счетчик).
   - Мобильное бургер-меню (выдвижная панель со всеми категориями и навигацией).
2. Главный баннер (Hero section): Стильный продающий блок с подборкой топ-гаджетов месяца и кнопкой перехода к каталогу.
3. Секции товаров:
   - "Популярные новинки"
   - "Лучшие видеообзоры"
   - Сетка карточек товаров. Каждая карточка содержит: качественное фото, название, рейтинг (звездочки), краткие характеристики, цену и заметную кнопку "Смотреть на Маркете" (с атрибутами реферальной ссылки).
4. Подвал (Footer): Ссылки на категории, разделы "О проекте", "Контакты", "Политика конфиденциальности", копирайт.

Дополнительные шаблоны и страницы (доступные из каталога):
- Страница категории (с фильтрами слева и адаптивной сеткой товаров).
- Страница детального просмотра товара (Карточка товара):
  - Хлебные крошки (Главная -> Категория -> Товар).
  - Крупное фото и название (H1).
  - Блок с подробными характеристиками (таблица).
  - Встроенный адаптивный видеоплеер (YouTube iframe) с обзором.
  - Текстовый блок с плюсами и минусами товара.
  - Крупная конверсионная кнопка "Купить на Яндекс Маркете" (с акцентным цветом и иконкой).
  - Блок "Похожие товары".
- Статические страницы: "О проекте", "Контакты", "Политика конфиденциальности" (аккуратный текст для модерации в Яндекс Дистрибуции).

Интерфейс должен быть на 100% адаптивным, быстрым, без лишних тяжелых библиотек, с использованием Tailwind CSS и иконок Lucide. Никаких упоминаний сторонних генераторов в коде и интерфейсе.
